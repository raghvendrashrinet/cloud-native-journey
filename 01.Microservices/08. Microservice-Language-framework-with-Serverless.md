| Architecture Tier          | Serverless Tech / Service Options                                                                 | Primary Role & Responsibility                                                                 |
|-----------------------------|--------------------------------------------------------------------------------------------------|------------------------------------------------------------------------------------------------|
| Frontend SPAs              | • Vercel Next.js • Amazon Amplify                                                                | Serverless UI hosting, automatic CDN edge routing, and single-page application rendering.      |
| Backend Microservices      | • AWS Lambda • Azure Functions • Google Cloud Functions • Vercel Edge Functions                  | Event-driven, auto-scaling compute execution for Catalog, Shopping Cart, Discount, and Ordering microservices. |
| Databases                  | • Amazon DynamoDB (NoSQL) • Azure CosmosDB (NoSQL) • Upstash Redis (In-Memory Cache)             | Fully managed, serverless database-per-service persistence with auto-scaling capacity.         |

| Message Brokers & Event Bus| • Amazon EventBridge & SNS • Azure Service Bus                                                   | Asynchronous pub/sub messaging backbone for event-driven workflows (e.g., OrderPlaced).        |

## 💡 Multi-Cloud Serverless Stack Summary
- `AWS Serverless Stack`: Amazon Amplify + AWS Lambda + Amazon DynamoDB + Amazon API Gateway + Amazon EventBridge / SNS
- `Azure Serverless Stack`: Azure Functions + Azure CosmosDB + Azure Gateway + Azure Service Bus
- `Independent / Edge Stack`: Vercel Next.js / Edge Functions + Upstash Redis

### 🧩 Architectural Components & Azure Service Mapping
**1. Gateway & Ingress Layer**
Azure API Management (APIM): Replaces self-managed API Gateways. Provides rate limiting, JWT token validation, CORS management, and routes HTTPS requests directly to backend Azure Function Apps.

**2. Azure Function Microservices**
- `Catalog Service`: Handles product listings, dynamic metadata, and catalog searches.
- `Compute`: Azure Functions (Node.js / Python) with HTTP Triggers.
- `Database`: Azure Cosmos DB (NoSQL API) for flexible document schemas and low-latency global reads.
- `Shopping Cart Service`: Manages user shopping sessions and temporary cart items.
- `Compute`: Azure Functions (Node.js / C#).
- `Database`: Azure Cache for Redis (Enterprise / Serverless Tier) for high-speed session storage.
- `Discount Service`: Evaluates active promo codes, pricing coupons, and discount logic.
- `Compute`: Azure Functions (.NET 8 Isolated Worker).
- `Database`: Azure Cosmos DB (Core SQL API) for fast rule lookups.
- `Ordering Service`: Coordinates transactional checkout execution and order state updates.
- `Compute`: Azure Functions (.NET 8 / Java) using Durable Functions for long-running workflow state machines.
- `Database`: Azure SQL Database (Serverless Tier) for ACID-compliant transactional consistency.

**3. Asynchronous Messaging & Event Backbone**
- **Azure Service Bus & Azure Event Grid**: Replaces self-managed Kafka or RabbitMQ clusters.
- **Azure Service Bus**: Handles reliable queueing and topic subscriptions for financial processing and order fulfillment.
- **Azure Event Grid**: Publishes domain events (e.g., OrderPlaced) to trigger downstream Azure Functions (Inventory, Billing, Shipping, Notifications) in real time.
