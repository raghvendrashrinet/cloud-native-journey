## Reference Project: .Net Microservices - Cloud-Native E-Comm.md
This reference project demonstrates a production-ready, event-driven e-commerce platform built on .NET 8, implementing domain-driven design, CQRS, and polyglot persistence.

## 🛠️ Core Services & Repositories

| Component        | Tech Stack & Persistence                                | Primary Communication & Role                                                                 |
|------------------|---------------------------------------------------------|----------------------------------------------------------------------------------------------|
| Catalog.API      | ASP.NET Core Minimal APIs, Marten (PostgreSQL)          | Handles product listings and dynamic schemas using Vertical Slice Architecture & CQRS.       |
| Basket.API       | ASP.NET Core Web API, Redis Cache                       | Manages user shopping carts. Calls Discount.Grpc synchronously and publishes checkout events. |
| Discount.Grpc    | High-performance gRPC, SQLite / PostgreSQL              | Evaluates promotional pricing and coupon rules via Protobuf contracts.                       |
| Ordering.API     | Clean Architecture, Entity Framework Core (SQL Server)  | Consumes BasketCheckout events asynchronously to execute order fulfillment workflows using DDD practices. |
| API Gateway      | Yarp Reverse Proxy / Ocelot                              | Single entry point providing request routing, load balancing, and rate limiting.             |
| Event Bus        | RabbitMQ with MassTransit                               | Decoupled asynchronous messaging backbone for event-driven microservice workflows.           |

## 🐍 Production-Grade Python Microservice Alternatives

1. FastAPI Microservices E-Commerce (fastapi-microservices)
   - `Core Stack`: FastAPI, Async SQLAlchemy, PostgreSQL, Redis, RabbitMQ / Celery.
   - `Architecture`: Uses FastAPI for ultra-low latency REST & gRPC endpoints, Redis for session caching, and Celery for asynchronous background job workers.
   - `Key Features`: OpenAPI/Swagger documentation generated automatically, Pydantic for validation, and Docker Compose deployment.
2. Event-Driven Python Microservices (kafka-python-microservices)
   - `Core Stack`: FastAPI / Flask, Apache Kafka, MongoDB, PostgreSQL.
   - `Architecture`: Replaces MassTransit/RabbitMQ with Kafka event streams. The Order service emits OrderCreated events consumed asynchronously by Inventory and Notification services.
